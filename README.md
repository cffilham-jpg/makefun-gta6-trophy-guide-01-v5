Leonida Ledger v5 is a GTA VI trophy guide covering 55 trophies through 218 cited steps. Of those steps, 175 have two or more citations, drawing on 20 sources. A staged roadmap helps organize your progress, while per-trophy confidence notes explain how well each entry is supported.

## Run locally

```sh
node serve.ts
```

Then open http://localhost:8080.
